# Canvas Studio

Canvas Studio 是一个面向移动端画布的图文排版工具。用户可以通过模块化编辑器制作个人介绍、兴趣展示、社交名片和长图内容，并导出图片或可再次导入的卡片短码。

## 当前主线

根目录 React + Vite Web 版本是唯一开发主线，支持桌面端、手机浏览器和 PWA。

`taro-project/` 已弃用，仅保留历史代码，不纳入日常开发和验证。未来如需微信小程序，优先使用 Web 版本配合 `web-view` 壳。

## 本地运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run lint
npm run build
```

## 主要能力

- 模块化图文排版：标题、文本、Markdown、图片、资料卡、时间轴、标签、作品、音乐、社交链接、二维码等。
- 拖拽排序、模块编辑、撤销/重做。
- 手机画布和 A4 比例模式，实时预览会标记分页位置。
- 风格预设、背景图层、自定义字体、颜色和排版设置。
- PNG 长图导出，以及 `card://` 短码导入导出。
- 浏览器本地持久化和 PWA 安装支持。

## 数据说明

项目默认保存在当前浏览器本地，不上传到服务端。图片、字体和外部内容会影响项目体积；重要卡片建议及时导出短码备份。

音乐和作品模块会按用户输入的链接请求第三方接口，接口不可用时会保留手动填写能力。
