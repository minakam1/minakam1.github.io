# 多功能排版工具 - 需求文档

## 项目概述
面向年轻人的**模块化排版工具**。
不是固定模板，而是像搭积木一样自由组合各种模块。
可以做出简历、游戏排名图、扩列条，或者混搭风格。

---

## 一、核心理念

### 1.1 模块化设计
像 Notion 一样，自由添加、删除、拖拽排序各种模块：
- 文字块
- 图片块
- 列表块
- 进度条
- 标签云
- 评分星星
- 二维码
- ...

### 1.2 高度自定义
- 背景：纯色 / 渐变 / 图片 / 透明
- 字体：多种中文字体选择
- 配色：完全自定义主题色
- 布局：间距、圆角、阴影可调
- 尺寸：固定比例 / 自由尺寸

### 1.3 数据可移植
所有编辑内容可以导出为一个**短码**（Base64压缩JSON）：
- 复制粘贴即可分享
- 扫码导入
- 保存到本地

## 四、数据系统

### 4.1 数据结构

```typescript
interface CardProject {
  id: string;
  version: '1.0';
  createdAt: number;
  updatedAt: number;
  
  // 画布设置
  canvas: {
    width: number;
    height: number;
    background: {
      type: 'solid' | 'gradient' | 'image' | 'transparent';
      value: string;
    };
    padding: number;
  };
  
  // 样式设置
  style: {
    fontFamily: string;
    baseFontSize: number;
    lineHeight: number;
    colors: {
      primary: string;
      secondary: string;
      background: string;
      text: string;
    };
    borderRadius: number;
    shadow: 'none' | 'sm' | 'md' | 'lg';
  };
  
  // 模块列表
  modules: Module[];
}

interface Module {
  id: string;
  type: 'heading' | 'text' | 'image' | 'profile' | 'infolist' | 
        'timeline' | 'progress' | 'tags' | 'rating' | 'tierlist' | 
        'grid' | 'quote' | 'social' | 'contact' | 'divider' | 'qrcode';
  data: any;
  style?: {
    align?: 'left' | 'center' | 'right';
    color?: string;
    background?: string;
  };
}
```

### 4.2 导入/导出

**导出为短码：**
```
card://eyJpZCI6Inh4eCIsIm1vZHVsZXMiOls...（Base64压缩）
```

**导出选项：**
- 复制短码（最常用）
- 生成二维码（扫码导入）
- 保存为文件（.card 格式）
- 导出图片（PNG/JPG）

**导入方式：**
- 粘贴短码
- 扫描二维码
- 上传文件
- 从本地历史恢复

## 七、技术实现

### 7.1 核心栈
- React 18 + Vite
- Tailwind CSS
- Zustand（状态管理）
- @dnd-kit（拖拽排序）
- html2canvas（导出图片）
- LZ-String（数据压缩）

### 7.2 数据压缩
使用 LZ-String 压缩 JSON，让短码更短：
```javascript
// 导出
const json = JSON.stringify(project);
const compressed = LZString.compressToBase64(json);
const code = 'card://' + compressed;

// 导入
const compressed = code.replace('card://', '');
const json = LZString.decompressFromBase64(compressed);
const project = JSON.parse(json);
```
