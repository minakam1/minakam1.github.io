# Hexo 博客搭建与 GitHub Pages 部署指南 - 验证清单

* [x] 检查 Node.js 和 npm 是否已成功安装（运行 `node -v` 和 `npm -v` 验证）

* [x] 检查 Hexo CLI 是否已成功安装（运行 `hexo -v` 验证）

* [x] 检查 Hexo 项目是否成功初始化（目录结构正确）

* [x] 检查 Fluid 主题是否正确安装和配置（本地预览效果）

* [x] 检查 hexo-deployer-git 插件是否成功安装

* [x] 检查 \_config.yml 文件中的 deploy 配置是否正确

* [x] 检查 GitHub 仓库是否按照规范创建（username.github.io 格式）

* [x] 检查博客是否成功部署到 GitHub Pages（访问 username.github.io）

* [x] 检查新文章是否成功创建（文件存在且格式正确）

* [x] 检查新文章是否成功发布到 GitHub Pages（博客中显示）
